# Tannu Priya — Premium Developer Portfolio & Case Studies

An award-winning, editorial developer portfolio built for **Tannu Priya** (Full Stack Developer | React.js Developer | Software Engineer).

Designed with a high-craft aesthetic inspired by Apple, Linear, and Awwwards creative technology studios: deep charcoal / midnight obsidian backdrop, metallic silver and subtle champagne accents, oversized editorial typography, interactive Three.js 3D WebGL canvas, smooth Lenis scrolling, and in-depth engineering case studies.

---

## ✦ Key Highlights & Architecture

- **Cinematic 3D Hero Canvas**: Built with Three.js featuring an interactive metallic icosahedron with procedural liquid wave vertex displacement, dynamic point/key/rim lighting, and orbiting stardust particles responding to pointer coordinates with smooth damping.
- **Editorial About & Philosophy**: Narrative of logic and craft, interactive development mindset tabs (Algorithmic Logic, Scalable Architecture, AI Horizons), and verified academic/technical credentials.
- **Interactive Skill Universe**: Categorized into 6 domains (Frontend, Backend, Languages, Databases, Tools, Core Computer Science) with animated badges, core strength indicators, and algorithmic problem-solving highlights.
- **4 In-Depth Featured Case Studies**:
  1. **MEDISHARE**: Real-time medicine-sharing platform connecting pharmacies and NGOs with DSA expiry prioritization (~25% resource utilization improvement).
  2. **AURELLE**: High-craft lifestyle & luxury fashion digital brand experience with cinematic visual storytelling and responsive editorial layouts.
  3. **REALTIMEBID ENGINE**: Dynamic live auction platform with responsive real-time bidding interactions (React, PHP, MySQL).
  4. **DISASTER RELIEF RESOURCE ALLOCATOR**: Priority-based resource distribution system with algorithmic optimization (~30% efficiency improvement over FCFS).
- **Interactive Case Study Modal**: Deep dive into Problem Statement, Engineered Solution, Key Architecture, Contribution, and Technical Challenges & Solutions.
- **Professional Timeline**: Ediglobe Web Developer Intern (April 2025 – July 2025) with structured responsibilities, technologies, and achievements.
- **Interactive Learning Roadmap**: 7 progressive milestones from Programming Fundamentals to AI Horizons, strictly separated from verified certifications.
- **Executive Resume Showcase**: Full-fidelity digital resume with instant "Download CV / Print" and "Copy Plain Text" actions, easily replaceable with `/public/resume.pdf`.
- **Contact & Celebration Experience**: Interactive contact form with client-side validation, confetti celebration, one-click email copy, GitHub/LinkedIn links, and a live Indian Standard Time (IST) clock.
- **Buttery Smooth Interactions**: Integrated Lenis smooth scrolling, Framer Motion viewport reveals, custom magnetic cursor, and optional Web Audio micro-sound synthesis.

## ✦ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS with custom glassmorphism utilities & color palette
- **3D Graphics**: Three.js (WebGL Renderer, ACESFilmic Tone Mapping, procedural vertex shaders)
- **Smooth Scrolling**: Lenis
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVG Icons
- **Effects**: Canvas Confetti + Web Audio API synthesizer

## ✦ Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates an optimized, minified production bundle in `/dist`.

### 4. Preview Production Build
```bash
npm run preview
```

---

## ✦ Customization Guide

- **Personal Information & Data**: Modify `src/data/portfolioData.js` to update bio, statistics, skill items, projects, or contact links.
- **Profile Photo**: Place your portrait photo in `public/profile.jpg` or `src/assets/` and link it inside `src/components/About.jsx`.
- **Resume PDF**: Place your PDF file in `public/resume.pdf` to allow recruiters to download your file directly.
